comandos para container

display: grid; transforma o container em uma grid

grid-template-columns: auto auto // define a quantidade de colunas "auto auto são duas colunas "

grid-template-rows: 100px 100px 100px; // define a altura de cada linha na grid

gap: 20px; // define o gap de cada item na grid

aling-intems // normal == stretch / start / center / end /

justify-items // normal == stretch / start / center / end /

aling-content // start == stretch / center / end / space-between / space-evenly / space-around /

justify-content // start == stretch / center / end / space-between / space-evenly / space-around /

grid-auto-row: 100px // caso uma nova linha implícita seja adicionada ela recebe esse tamanho

grid-auto-column: 100px // caso uma nova coluna implícita seja adicionada ela recebe esse tamanho

grid-auto-flow: row // define a direção do fluxo da grid, pode ser row ou column

simplificação

justify-items e aling-intems == place-itens = 1 aling 2 justify //

justify-content e aling-content == place-content = 1 aling 2 justify

grid-template-columns e grid-template-rows == grid-template = rows / columns

reapeat

reapeat (vezes, tamanho) // repete o tamanho definido o numero de vezes definido simplificação grid-template: repeat(3, 100px) / repeat(2, 100px); // 3 linhas de 100px e 2 colunas de 100px

fraçoes e span

frações são usadas para ter maior controle sobre o tamanho dos itens na grid span é usado para definar quaantos linhas ou colulas o item de ESPANDIR apartir do seu ponto de inicio

comandos de itens

grid-row-start: 1; // define a linha de inicio do item na grid grid-row-end: 3; // define a linha de fim do item na grid grid-column-start: 1; // define a coluna de inicio do item na grid grid-column-end: 3; // define a coluna de fim do item na grid simplificação grid-row: 1 / 3; // define a linha de inicio e fim do item na grid grid-column: 1 / 3; // define a coluna de inicio e fim do item na grid grid-area: 1 / 1 / 3 / 3; // define a área do item na grid (linha de inicio, coluna de inicio, linha de fim, coluna de fim)
